🚀 ROADMAP DE ESTUDO PYTHON (BASEADO NA TRILHA DO CURSO EM VÍDEO - GUSTAVO GUANABARA)

Este roadmap propõe um caminho estruturado seguindo a metodologia prática e didática do curso em vídeo de Python do professor Gustavo Guanabara.

🟢 PASSO 1: MUNDO 1 - FUNDAMENTOS
- Objetivo: Primeiros passos, configurar ambiente e entender a sintaxe básica.
- Conteúdo:
  - 🖥️ Instalação do Python e VS Code.
  - ⌨️ Comandos de saída (print) e entrada (input).
  - 🔢 Tipos primitivos e saída de dados.
  - ➕ Operadores aritméticos.
  - 📚 Utilizando módulos (biblioteca math).
  - 📝 Manipulação de textos (strings).
  - 🚦 Condições simples e compostas (if, else).

🟡 PASSO 2: MUNDO 2 - ESTRUTURAS DE CONTROLE
- Objetivo: Criar lógica de programação mais complexa e estruturada.
- Conteúdo:
  - 🚥 Condições aninhadas (if, elif, else).
  - 🔄 Estruturas de repetição: Laço for.
  - 🔁 Estruturas de repetição: Laço while.
  - 🛑 Interrompendo repetições (break).

🔴 PASSO 3: MUNDO 3 - ESTRUTURAS COMPOSTAS
- Objetivo: Trabalhar com grandes conjuntos de dados e modularização.
- Conteúdo:
  - 📦 Tuplas.
  - 🗒️ Listas (parte 1 e 2).
  - 📖 Dicionários.
  - ⚙️ Funções (parte 1 e 2).
  - 🔭 Escopo de variáveis.
  - ⚠️ Tratamento de erros e exceções (try, except).
  - 🧩 Modularização (criação de pacotes e módulos).

🛠️ PASSO 4: PROJETO PRÁTICO (SISTEMA FINAL)
- Objetivo: Integrar tudo que foi aprendido em um projeto de sistema.
- Ação: Criação de um sistema de menu e manipulação de arquivos .txt para persistência de dados.

🌟 PASSO 5: CONSTÂNCIA E ESPECIALIZAÇÃO
- Objetivo: Seguir para bibliotecas avançadas (Pandas, Numpy, etc) e áreas específicas.
- Ação: Continuar criando projetos próprios para consolidar o conhecimento.
- Evolução: Melhore a organização do código (documentação, módulos, pastas, testes, logs) e utilize Git/GitHub.

💡 RECOMENDAÇÃO FINAL
- Assista, anote e, principalmente, pratique cada exercício proposto no curso.
- A melhor forma de aprender é fazendo de 5 a 10 projetos na área de interesse.
- Mantenha a constância.
